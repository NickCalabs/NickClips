API Usage

Send a POST request to download a video:

curl -X POST {{ request.url_root }}api/download \
  -H "Content-Type: application/json" \
  -H "X-API-Key: YOUR_API_KEY" \
  -d '{"url": "https://youtube.com/watch?v=..."}'

Response:

{
  "message": "Download queued successfully",
  "slug": "abc12345",
  "redirect": "/video/abc12345"
}

iOS Shortcut

Use this iOS Shortcut to quickly save videos from any app's Share Sheet and get a NickClips link copied to your clipboard.

How it works: Share a video URL from YouTube, Twitter, Reddit, etc. The shortcut sends it to your NickClips server and copies the shareable link.
Setup Instructions
  1. Generate your API key (above) if you haven't already
  2. Create a new Shortcut on your iPhone/iPad:
    • Open the Shortcuts app
    • Tap + to create a new shortcut
    • Tap the shortcut name and choose "Show in Share Sheet"
    • Set "Receive" to URLs
  3. Add these actions in order:
    1. Get URLs from Input
    2. Get Contents of URL with:
      • Method: POST
      • URL: {{ request.url_root }}api/download
      • Headers: X-API-Key = your API key
      • Headers: Content-Type = application/json
      • Request Body: JSON with key url = URLs (from step a)
    3. Get Dictionary Value - get slug from Dictionary
    4. Text - {{ request.url_root }}video/ + Dictionary Value
    5. Copy to Clipboard - Text
    6. Show Notification - "NickClips link copied!"
  4. Name your shortcut something like "Save to NickClips"
That's it! Now when you share any video URL, choose your shortcut from the Share Sheet and the NickClips link will be copied to your clipboard.
